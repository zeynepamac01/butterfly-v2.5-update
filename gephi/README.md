# Heart–FTU Vascular Network (Gephi)

## Description
This folder contains a Gephi visualization of the vascular pathways connecting the heart and Functional Tissue Units (FTUs).

## Data Sources
- `Table_S1.csv` (FTU-to-vessel mapping)
- `asct-blood-vasculature-edges.csv` (heart and blood vasculature connections)

## Files
- `heart_vascular_network.gephi` – Gephi project
- `heart_vascular_network.svg` – exported visualization
- `gephi_nodes_main.csv` – node table
- `gephi_edges_main.csv` – edge table

## Color Scheme
- **Heart** – Black
- **Left ventricle** – Red
- **Right atrium** – Blue
- **Right ventricle** – Purple
- **Left atrium** – Purple
- **FTUs** – Green
- **Blood vessels** – Light gray

## Software
- Gephi 0.11.2
